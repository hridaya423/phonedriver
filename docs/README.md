# docs

phonedriver is an open-source MCP server and CLI that lets AI agents like Claude Code see and control Android and iOS phones.

- `compare.md`: phonedriver against adb, phone-harness and mobile-mcp. `../llms.txt`: a link index for language models.

- `architecture.md`: how phonedriver is built. `protocol.md`: the daemon and agent wire formats. `decisions.md`: why each design choice was made.
- `plans/`: the master plan and per-phase plans. `spikes/`: results of throwaway experiments.
- `bench/`: measured latency and suite results. `research/`: competitor notes.
- `audits/`: agent-experience and developer-experience audits.
- `release-checklist.md`: what stands between the repo and a release.
